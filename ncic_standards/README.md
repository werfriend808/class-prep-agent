# NCIC 성취기준 데이터셋 (전체 학년·전체 과목)

실전 프로젝트 2("AI 챗봇 기반 수업계획안 생성")에서 "NCIC 교육과정 근거 제시"에 쓸
성취기준 데이터셋. 2022 개정 교육과정 고시 원문(PDF)에서 직접 파싱했다.

## 범위: 왜 "전체 학년·전체 과목"인가 (2026-08-10 갱신)

처음엔 실전 1 샘플 데이터(고1 자료 위주)에 맞춰 **고1 공통 과목 5개(157건)**로만
범위를 좁혔었다. 하지만 실전 2 공식 과제 스펙(멋사 NLP5기 프로젝트 안내 Notion
페이지)의 "프로젝트 범위 - 지원 범위"에 **"대상 학년/과목: 전체 (제한 없음)"**이라고
명시되어 있는 것을 뒤늦게 확인하고, 보유 중이던 2022 개정 교육과정 별책 PDF
16종(초~고 전 학년/전 과목) 전체를 다시 파싱해서 데이터셋을 대폭 확장했다.

## 스키마 (`achievement_standards.json`)

```json
{
  "code": "10통사1-01-01",
  "subject": "사회",
  "course": "통합사회1",
  "grade": "고등학교 공통",
  "text": "인간, 사회, 환경을 바라보는 시간적, 공간적, 사회적, 윤리적 관점의 의미와 특징을 사례를 통해 파악한다.",
  "source_doc": "[별책7] 사회과 교육과정.pdf"
}
```

- `code`: 성취기준 코드(교육부 고시 원문 그대로). 앞자리 숫자가 학년군을 나타낸다
  (2=초1~2, 4=초3~4, 6=초5~6, 9=중1~3, 10=고등학교 공통, 12=고등학교 선택).
- `subject`: 위 표의 16개 과목명 중 하나 (파일 단위로 부여).
- `course`: 세부 과목명(예: "통합사회1", "문학", "인공지능 기초"). 되도록 원문의
  과목별 소제목(예: "독서와 작문\n1. 성격")에서 자동 추출했고, 고등학교 "공통"
  과목(공통국어1·2, 통합사회1·2, 한국사1·2, 공통수학1·2, 기본수학1·2, 공통영어1·2,
  기본영어1·2, 통합과학1·2, 과학탐구실험1·2)은 원문 제목이 "공통국어1, 공통국어2"처럼
  콤마로 묶여 있어 대신 성취기준 코드 자체에서 복원했다. 초/중학교는 학년군 전체가
  하나의 교과라 세부 과목 구분이 없어 `course == subject`다.
- `grade`: 학년군 라벨 6종 중 하나 — "초등 1~2학년" / "초등 3~4학년" /
  "초등 5~6학년" / "중학교 1~3학년" / "고등학교 공통" / "고등학교 선택".
  `src/ncic_matcher.grade_bands_for()`가 사용자가 말하는 구체적인 학년("고1" 등)을
  이 라벨로 변환해 필터링한다.
- `text`: 성취기준 문장 원문 (해설·적용 시 고려사항은 제외하고 성취기준 자체만).
- `source_doc`: 원본 PDF 파일명 (원문 확인용).

## 파싱 방법 (재현 가능하도록 기록)

`pypdf`로 PDF 텍스트를 추출한 뒤, 학년군 접두어를 포함한 성취기준 코드 패턴
(`\[(2|4|6|9|10|12)[가-힣A-Za-z][가-힣A-Za-z0-9]{0,7}-?\d{2}-\d{2}\]`)으로
전체 문서에서 코드+본문을 한 번에 추출했다 (기존엔 문서당 5개 과목만 수작업으로
좁혀서 추출했지만, 16개 문서·수천 건 규모에서는 코드 패턴 하나로 일반화하는 쪽이
현실적이었다).

- **중복 처리**: 같은 코드가 "나. 성취기준" 목록과 "(가) 성취기준 해설"에 중복
  등장하므로 최초 등장(목록 쪽)만 채택.
- **본문 자르기**: 다음 성취기준 코드가 나오거나 "성취기준 해설"/"성취기준 적용"
  같은 소제목이 나오면 그 앞까지만 잘라냈다.
- **세부 과목명 추출**: 원문에서 "과목명\n1. 성격" 또는 "과목명\n교육과정 설계의
  개요" 패턴이 나오는 위치를 과목 구간의 경계로 삼고, 그 이후 코드는 해당 과목명을
  달았다. 고등학교 "공통" 과목은 이 패턴이 안 맞아(콤마로 묶인 제목) 코드 자체에서
  과목명을 복원(위 스키마 설명 참고).

## 알려진 한계

1. **수식·특수기호가 이미지/자간 조정으로 삽입된 항목은 텍스트가 비거나 깨짐.**
   예: `10공수2-01-07`("...축, 축, 직선 에 대한..." → 원문은 "x축, y축, 직선
   y=x"), `10공수2-03-04`/`10공수2-03-05`(유리함수·무리함수 수식 누락),
   `10통사1-04-02`(글자 사이 공백 삽입). PDF 텍스트 추출의 근본적 한계라 전체
   4,199건 규모에서도 비슷한 케이스가 소수 더 있을 수 있다 — 정확한 문구가
   필요하면 원문 PDF를 확인해야 한다.
2. **세부 과목명(course)이 상위 과목명(subject)으로만 표시되는 경우가 있다.**
   고등학교 선택과목 중 교양 계열은 원문 소제목 형식을 특이하게 써서 일부(약
   40건, 한문/음악/미술/국어 각 소수)는 세부 과목명을 못 뽑고 상위 과목명으로
   대체됐다. 매칭 자체(과목/학년 필터링)에는 지장 없고, 계획안에 표시되는
   출처 표기가 "한문" 대신 "한문Ⅰ" 같은 세부명이 아니라 "한문"으로만 나올 수
   있다는 정도의 영향이다.
3. **자동 파싱이라 소수(약 15건, 전체의 0.4% 미만)는 성취기준 해설 문구가 일부
   섞여 들어간 경우가 있다.** 정규식 기반 절 구분이 모든 문서 포맷의 예외를
   완벽히 커버하지는 못했다.
4. 초/중학교는 학년군 전체가 하나의 교과라 `course == subject`인 게 정상이다
   (세부 과목이 애초에 없음 — 한계가 아니라 정상 동작).
