# NCIC 성취기준 데이터셋 (고1 공통 과목)

실전 프로젝트 2("AI 챗봇 기반 수업계획안 생성")에서 "NCIC 교육과정 근거 제시"에 쓸
성취기준 데이터셋. 2022 개정 교육과정 고시 원문(PDF)에서 직접 파싱했다.

## 출처

Stanley가 확보한 2022 개정 교육과정 별책 PDF 15종 중, 고1 공통 과목과 관련된 4개 문서에서 추출:

| 파일 | 과목 |
|---|---|
| [별책5] 국어과 교육과정.pdf | 국어 |
| [별책8] 수학과 교육과정 (2).pdf | 수학 |
| [별책14] 영어과 교육과정.pdf | 영어 |
| [별책7] 사회과 교육과정.pdf | 사회(한국사·통합사회) |

## 범위: 왜 "고1 공통 과목"만인가

각 원문 PDF는 초1~고3 전체 학년군, 모든 선택과목(일반/진로/융합선택)을 담고 있어
문서당 수백 페이지에 달한다(예: 사회과 316페이지). 실전 1의 golden set이 Notion
샘플 데이터(고1 자료 위주)로 범위를 좁혔던 것과 같은 이유로, 여기서도 실전 1
데이터셋과 겹치는 **고1 공통 과목**(국어/수학/영어의 "공통국어1·2" 등, 사회의
"한국사1·2"·"통합사회1·2")만 우선 추출했다.

**코드/파이프라인 자체는 학년에 종속되지 않는다** — 나중에 다른 학년/과목 문서를
같은 방식으로 파싱해서 이 데이터셋에 이어붙이면 그대로 확장된다.

## 스키마 (`go1_common_subjects.json`)

```json
{
  "code": "10통사1-01-01",
  "subject": "사회",
  "course": "통합사회1·2",
  "grade": "고1",
  "text": "인간, 사회, 환경을 바라보는 시간적, 공간적, 사회적, 윤리적 관점의 의미와 특징을 사례를 통해 파악한다.",
  "source_doc": "[별책7] 사회과 교육과정.pdf"
}
```

- `code`: 성취기준 코드(교육부 고시 원문 그대로)
- `subject` / `course`: 과목명 / 세부 과목(공통국어1·2 등, 1·2 두 과목을 하나로 묶어 수집)
- `grade`: 현재는 전부 "고1"
- `text`: 성취기준 문장 원문 (해설·적용 시 고려사항은 제외하고 성취기준 자체만)
- `source_doc`: 원본 PDF 파일명 (원문 확인용 — NCIC 사이트에서 같은 제목으로 찾을 수 있음)

## 파싱 방법 (재현 가능하도록 기록)

PDF에서 `pypdf`로 텍스트를 추출한 뒤, `[코드] 텍스트` 패턴(정규식
`\[([0-9A-Za-z가-힣]+-\d{2}-\d{2})\]\s*(.*?)(?=\[다음코드\]|끝)`)으로 성취기준을
분리했다. 같은 코드가 "나. 성취기준" 목록과 "(가) 성취기준 해설"에 중복 등장하므로
**최초 등장(목록 쪽)만 채택**하고, "성취기준 해설"/"성취기준 적용" 같은 소제목이
나오면 그 앞까지만 잘라냈다. 페이지 넘어가는 지점에 섞여 들어오는 머리말/꼬리말
("OOO과 교육과정 96" 같은)도 정규식으로 제거했다.

## 알려진 한계 (실전 1의 "노이즈 케이스"와 같은 성격)

1. **수식·변수 기호가 이미지/특수 폰트로 삽입된 항목은 텍스트 추출 시 빈칸으로 빠짐.**
   예: `10공수2-01-07`("원점, 축, 축, 직선 에 대한 대칭이동을...", 원문은 "x축, y축,
   직선 y=x"), `10공수2-03-04`/`10공수2-03-05`(유리함수·무리함수 수식 누락). 원문
   PDF를 직접 봐야 정확한 성취기준을 알 수 있다.
2. **`10통사1-04-02`는 글자 사이에 공백이 끼어 추출됨** (PDF 원본의 강조/자간 조정
   렌더링 때문으로 추정) — 의미는 통하지만 표기가 부자연스럽다.
3. 위 두 케이스를 빼면 나머지 153건은 육안 검수 결과 정상.
4. 과목명이 원문에서도 붙여쓰기/띄어쓰기가 섞여 있을 수 있음(실전 1의 "통합사회" vs
   "통합 사회1"과 비슷한 문제) — 매칭 로직에서 문자열 완전일치보다는 포함/유사
   매칭을 고려할 것.
